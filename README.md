## What belongs here?

This list focuses on tools that are useful directly from a web browser:

- **Browser-local tools** - process files or data on your device when possible.
- **Web utilities** - practical tools that solve a task without installation.
- **Open web apps** - editors, converters, generators, playgrounds, and diagnostics.
- **Tool directories** - curated places to discover more browser-based tools.

This repository is maintained as a practical discovery list, not a paid directory. Submissions should be genuinely useful, specific, and easy to access.

## Legend

| Mark | Meaning |
|---|---|
| `local-first` | Core work can happen locally in the browser |
| `open-source` | Source code is publicly available |
| `privacy-first` | Strong privacy posture or no-upload workflow |
| `pwa` | Installable or usable like an app |
| `directory` | Helps discover other tools |

## Image and Media Tools

- [24Picture](https://24picture.com) - Browser-local image toolkit with converters, compressors, editors, GIF tools, batch conversion, and PWA support. `local-first` `privacy-first` `pwa`
- [Squoosh](https://squoosh.app/) - Image compression and format conversion from the browser, originally by GoogleChromeLabs. `local-first` `open-source`
- [SVGOMG](https://jakearchibald.github.io/svgomg/) - Web UI for SVGO, useful for optimizing SVG files before shipping them. `local-first` `open-source`
- [Photopea](https://www.photopea.com/) - Advanced browser-based image editor with PSD, vector, and raster workflows.
- [Excalidraw](https://excalidraw.com/) - Virtual whiteboard for sketch-style diagrams and collaboration. `open-source`
- [tldraw](https://www.tldraw.com/) - Whiteboard and drawing app built for the web. `open-source`
- [Kapwing](https://www.kapwing.com/tools) - Collection of browser-based media editing tools for creators.
- [EzGIF](https://ezgif.com/) - Long-running web toolkit for GIF editing, conversion, resizing, cropping, and optimization.

- [StackBlitz](https://stackblitz.com/) - Browser-based development environment for web apps.
- [CodePen](https://codepen.io/) - Frontend playground for HTML, CSS, and JavaScript experiments.
- [JSFiddle](https://jsfiddle.net/) - Lightweight online editor for testing JavaScript, CSS, and HTML snippets.
- [Regex101](https://regex101.com/) - Regular expression tester with explanations, examples, and flavor support.

## Selection Criteria

A tool is more likely to be accepted if it is:

- Directly usable from a browser without installing desktop software.
- Useful for a clear task: convert, edit, generate, analyze, write, inspect, or debug.
- Stable enough for real users, with a working HTTPS URL.
- Transparent about privacy, pricing, and limitations.
- Not purely promotional, affiliate-only, or a thin landing page.

A tool may be rejected if it is:

- A gambling, adult, crypto spam, or low-value lead-gen page.
- Mostly a signup wall without demonstrating clear utility.
- A clone with no meaningful difference from existing entries.
- Submitted repeatedly across unrelated categories.
